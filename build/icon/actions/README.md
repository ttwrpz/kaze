Icons for the taskbar and Start menu actions (jump list), from
[Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons) (MIT License,
Copyright (c) 2020 Microsoft Corporation). 20 px filled versions, except snowflake and wind, which
only exist as outlines. `python build/icon/make_action_icons.py` turns them into the coloured
`.ico` files in `src/Kaze.App/Assets/Actions`.
